# Roadmap & Vision

Michi 道 est conçu pour évoluer d'un outil de prévision simple vers un centre de décision omnicanal complet pour l'e-commerce.

## 🚀 État Actuel (MVP Ready)
Nous avons posé les fondations solides du projet :
- **Infrastructure :** Monorepo, Docker, GraphQL.
- **Architecture :** DDD Hexagonal, Typage strict.
- **Cœur :** Pipeline de nettoyage des données et algorithmes de forecasting validés.

---

## 🎨 Identité Visuelle
Le design de Michi 道 repose sur trois piliers :
- **Simplicité :** Analyse complexe, rendu intuitif.
- **Vitesse :** Interface Optimiste, zéros chargements visibles.
- **Précision :** Données mathématiques rigoureuses.
